# Captures d’écran — Neivos Groupe

Déposez ici les captures réelles de la plateforme Neivos Groupe. Les noms ci-dessous sont des suggestions ; si vous utilisez d’autres noms, reprenez exactement ces noms dans le README principal.

## Noms conseillés

- `accueil.png` — page d’accueil de la plateforme
- `services.png` — présentation des services
- `technologies.png` — section technologies
- `connexion.png` — écran de connexion
- `inscription.png` — écran d’inscription
- `dashboard.png` — tableau de bord client
- `administration.png` — interface d’administration
- `gestion-services.png` — gestion des services
- `utilisateurs.png` — gestion ou liste des utilisateurs
- `demandes.png` — consultation des demandes

## Ajouter les captures

1. Ouvrez le dossier `docs/img/` sur GitHub.
2. Cliquez sur **Add file → Upload files**.
3. Sélectionnez les images depuis votre ordinateur.
4. Cliquez sur **Commit changes**.

Les fichiers image eux-mêmes doivent être téléversés dans ce dossier ; ce guide ne contient que des instructions.
